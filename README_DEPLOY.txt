SYNVIO marketing rework — deployment

1. Replace the contents of the marketing repository with the contents of this folder.
2. Deploy the marketing site to https://synviocore.xyz.
3. Confirm these public URLs open without sign-in:
   https://synviocore.xyz/privacy/
   https://synviocore.xyz/terms/
   https://synviocore.xyz/data-deletion/
4. In Meta App Settings, use the three URLs above for Privacy Policy, Terms of Service,
   and Data deletion instructions. Add synviocore.xyz to App domains.

The marketing chat uses the existing Flow bot. The floating launcher is hidden; visitors
open it using the “Talk to AI” buttons on the page.

This version includes the detailed Workspace preview, Email / Website chat / Instagram
channel cards, and the complete wallet-bonus and monthly-plan calculator.

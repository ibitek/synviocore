A practical example

1,000 incoming emails + 1,000 outgoing emails = $5 in message fees. If AI also uses 1 million uncached input tokens and 200,000 output tokens, add $3.60. Total usage: $8.60, before any handoffs or other usage.

Handoff: $0.002 once per conversation ($2 per 1,000 handoffs), added to message fees. Designer previews: no channel fees; generated replies still use the selected AI provider.

With BYOK: Synvio AI charge is $0. Your selected provider bills you directly. Message and handoff fees still apply.

USD usage rates are separate from wallet funding and optional plan payments. A wallet bonus adds service credits; it does not change the published usage rates. The SYNVIO AI safety cap is $0.15 per request; requests that cannot fit are rejected before generation.
